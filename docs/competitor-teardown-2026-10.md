# 竞品功能逆向拆解与复现可行性（2026-10）

> 配套文档：`docs/competitive-analysis-2026.md`（市场与价格）。本文只回答一个问题：**别人每个功能到底怎么做的，我们抄得起吗、值不值得抄。**
>
> 方法边界：本文的"逆向"指**黑盒功能拆解**——依据公开产品资料、帮助中心、商店页、免费层可观察行为，加上公开论文与工程常识推断实现方式。不反编译、不抓私有接口、不破解会员、不复制题库/音频/词库。**机制可复现 ≠ 资产可复制。**

判定口径（单人开发、熟悉现有代码）：

| 级别 | 含义 | 成本 |
|---|---|---|
| **A** | 现有代码可复用 ≥60%，无需新数据/新服务 | ≤ 3 人日 |
| **B** | 需新增数据、多用户或外部服务 | 1–3 周 |
| **C** | 需授权、资质或重资产，或对答辩无增益 | 不做 |

---

## 0. 一页结论

| # | 机制 | 来源 | 我们的现状 | 判定 | 优先级 |
|---|---|---|---|---|---|
| 1 | 对话结束的结构化课后报告 | Praktika / Speak | 面试有四维报告（`interview.js:142`），对话只有单句 tip | **A / 1.5d** | P0 |
| 2 | 阅读/听力划词即查、即入生词本 | 德语助手 | 对话已有点词收藏（`chat.js:67-93`），阅读是纯文本 | **A / 1d** | P0 |
| 3 | 留德时间轴（APS→语言→申请） | DUO | 无 | **A / 1d** | P0 |
| 4 | CEFR 学习路径（单元→关卡） | Duolingo / Babbel | 20 个模块平铺，无先后关系 | **A / 3–5d** | P1 |
| 5 | 段落级 AI 解析（长难句+翻译+语法点） | 每日德语听力 | `llm.js` 可复用，缺入口与缓存 | **A / 1–2d** | P1 |
| 6 | 配音/产出页（录→评→对比） | 每日德语听力 | 有录音评分与音素对齐，缺"作品"形态 | **A / 2d** | P2 |
| 7 | 同伴互评 | Busuu | 有 AI 批改，无多用户评价队列 | **B / 5d + 冷启动** | P2 |
| 8 | 班级 / 小组榜 | Duolingo | 有后端与账号，无班级模型 | **B / 5–8d** | P3 |
| 9 | 视频通话陪练 | Duolingo Max | 无实时音视频通道 | **C** | 不做 |
| 10 | 3D 虚拟人对话 | Praktika | 无 | **C** | 不做 |
| 11 | 25 万词条词典 | 德语助手 | 476 词（可扩到 1000+） | **C（授权）** | 不做 |
| 12 | 听力内容库规模 | 每日德语听力 | Tatoeba 300 句 + 85 篇阅读 | **B（版权+录制）** | 不正面比 |

**一句话：值得抄的 6 个机制全部是 A 级，加起来约 10 人日；C 级的四个都别碰。真正的壁垒不是功能，是内容资产与分发。**

## 1. 逐家拆解

### 1.1 Duolingo（含 Max）

- **核心循环**：通知 → 3–5 分钟一课 → XP/连胜 → 联赛排名。
- **机制实质**：
  - 组卷 = 按"用户能力 × 题目难度"预测答对概率，把练习控制在"有点难但做得对"的区间（官方称 Birdbrain，具体参数未公开，公开论文只给了 HLR 调度）；
  - 红心 = 稀缺性变现；连胜冻结/复活 = 损失厌恶；联赛 = 社会比较。
- **真壁垒**：亿级行为数据 + 内容量 + 品牌，不是算法（论文是公开的）。
- **复现判定**：
  - 组卷 **A**：`buildQueue`（`engine.js:59`）已有"HLR 濒危 + 到期 + 加权新词"，缺的是题目难度标定。加一层 Elo 式 `p = logistic(θ - d)`，把每次作答同时更新能力 θ 与题目难度 d，抽 `p≈0.7–0.85` 的题，2–3 天。
  - 冻结/复活 **已实现**（`store.js:29-32`、`:91-111`），不用再做。
  - 联赛 **B**，赛期内无收益。
  - Max 视频通话 **C**：实时链路 + 成本，演示收益低于嘴替。
- **可借鉴的只有一句**：把"今天为什么练这 20 个词"解释给用户听。他们讲不清，我们能。

### 1.2 Babbel

- **核心循环**：课程单元 → 对话练习 → 复习。
- **机制实质**：CEFR 大纲图谱（知识点有先修关系）+ 每课 authored 对话脚本 + ASR 纠音。
- **真壁垒**：课程编写（数千课，百人年）。
- **复现判定**：**A（技术）/ B（内容）**。路径层 3–5 天；真做完整 CEFR 课程是几个月，不做。
- **落点**：用现有 20 个模块 + 476 词 + 170 纠错句，映射成 A1→B1 的 9 个单元，只做"壳"，不新写课。

### 1.3 Busuu

- **核心循环**：练习 → 提交写作/口语 → 母语者批改 → 证书。
- **机制实质**：互评队列 + 贡献者信誉 + AI 预检；证书是与出版社合作的背书。
- **真壁垒**：社区流动性（冷启动）+ 认证资质。
- **复现判定**：AI 批改已有（`writing.js:178-235`）；互评 **B**（队列、评分卡、防刷）；证书 **C**。
- **落点**：双层反馈——AI 立即给分与逐句批注，同伴只做"复核 + 打分"；赛期内单机版可先用"AI 初评 + 规则复核"替代，不宣称有社区。

### 1.4 Speak

- **核心循环**：跟读 → 评分 → 重录，直到过线。
- **机制实质**：强制产出（不让打字）+ 音素级评分 + 课程脚本；产品约束比技术更关键。
- **真壁垒**：语音栈与口音数据。
- **复现判定**：**A**。评分已有（`engine.js:221` 三维 + `phonetics.js:132` 音素对齐）；上限取决于 ASR，后端 Whisper 通道已具备。
- **落点**：加"必须说满 N 秒/至少 N 词"的门槛与重录循环；报告直接给最小对立对（ü/u、ö/o、ch 双音位），这是他们只给分数、不给定位的地方。

### 1.5 Praktika

- **核心循环**：虚拟人对话 → 路径推进。
- **机制实质**：3D 头像 + TTS/口型 + 对话脚本；**课后反馈弱**是公开测评点名的短板。
- **真壁垒**：avatar 资产与渲染。
- **复现判定**：报告 **A**（面试已有四维 + 亮点/风险/建议/改写，`interview.js:142-181`）；头像 **C**。
- **落点**：把面试报告的骨架搬到对话，按场景给"错误类型分布 + 重复错误 + 下次三个重点"。

### 1.6 Talkpal / Langua / Gliglish

- **机制实质**：场景卡 + 提示词 + 纠错开关 + TTS，本质是 prompt 工程，无教学闭环。
- **复现判定**：**A（小时级）**，没有壁垒。
- **结论**：不要在"AI 能聊"上投入；要投"聊完之后系统记住了什么"。我们的场景只有 19 个（`corpus.js`/`corpus-ext.js`），但每个都能接 APS 追问链，这比 57 种语言值钱。

### 1.7 每日德语听力（欧路系）

- **核心循环**：选材 → 调语速 → 逐句精听 → 听写/跟读 → 打卡。
- **机制实质**：音频按句切分（时间戳）+ 播放器（变速/循环/单句）+ 打分 + 内容 CMS；AI 段落解析是 2026 年新增。
- **真壁垒**：版权内容与录制质量、老师推荐形成的使用习惯。
- **复现判定**：**A（技术）/ B（内容）**。五种题型、影子跟读三级、0.5–1.25× 变速我们都有（`listening.js:25-29`、`:87-92`）；内容 300 句对不过人家的日更库。
- **落点**：不正面比库，做"诊断→选材→复盘"：按薄弱音/薄弱题型推材料，材料可来自开放语料内容包（已有管线）。

### 1.8 德语助手（欧路系）

- **机制实质**：词典数据库（约 25 万德汉词条）+ 形态分析（变位、格）+ 离线发音 + 生词本 + 跨 App 划词。
- **真壁垒**：词典授权与装机量。
- **复现判定**：全量 **C**；**划词查词 A**。
- **落点**：把 `chat.js:67-93` 的点词逻辑抽成公共组件，接阅读正文、听力原文、写作批注三处；词库未命中时走 LLM 释义并标注"AI 释义，待校对"，不冒充词典。

### 1.9 Prepilingo（德奥考试专项）

- **机制实质**：考试题型库 + 限时模考 + 评分规则；价值在题型保真度与题量。
- **真壁垒**：题库（且真题有版权）。
- **复现判定**：框架 **A**（`mockexam.js:9-12` 四节限时已有）；题库 **B**（原创题，按题型仿写，不抄真题）。
- **落点**：把"模考"从展示功能变成诊断入口——交卷后直接生成薄弱题型清单并跳转对应专项。

### 1.10 DUO（Deutsch-Uni Online）

- **机制实质**：LMS + 导师批改 + 高校渠道；TestDaF 体系背景带来信任。
- **真壁垒**：机构渠道与认证。
- **复现判定**：渠道 **C**；**路径叙事 A**。
- **落点**：首页"留德时间轴"（APS 审核 → 语言考试 → 申请 → 签证），把 20 个模块挂到时间轴上，用户一眼知道"我现在在哪、下一步是什么"。这是最低成本的高感知功能。

### 1.11 真人课（欧那 / 新东方 / 歌德）

- **机制实质**：人对人的督学与即时反馈。
- **复现判定**：**不做**。定位是"课前预习 + 课后复盘"的训练系统，可给机构生成学员报告（B2B 增量），不与真人课抢"教学"。

### 1.12 Anki / 通用大模型

- **Anki**：FSRS 已实现（`engine.js:471-494`、`:569-579`），导入导出（Anki TSV）已有；缺卡片浏览器/编辑，优先级低。
- **通用大模型**：能聊、能讲，但**不会安排明天复习什么、没有能力画像、不会积累错误分布**。这正是"调度与测量"的位置。
- **落点**：答辩现场用算法沙盘（`engine.js:497-650`）改参数跑对照，证明"同一天 30 分钟，HLR 比固定间隔少复习 X%、遗忘事故低 Y%"——这是可验证的差异，不是话术。

## 2. A 级功能实现蓝图（P0–P2）

### 2.1 对话课后报告（P0，1.5 人日）

- **数据来源**：每轮已有 `LD.LLM.correct` 的 issues（`chat.js:137`）、tip、用户句长、场景 id；错误类型已由 `ruleTypeOf` 归为 7 类（`llm.js:87-95`）。
- **聚合**：`{scene, turns, errorTypes:{语序:3,...}, repeats:[同一错误片段≥2次], newWords, dims:{任务完成,语法,词汇,流利}, next:[3条]}`。
- **生成**：本地模板保证离线可出报告；有 AI 时补一段中文总评与改写示范。
- **UI**：复用面试报告的环图 + 四维条 + 亮点/风险/建议（`interview.js:142-181`），加"再来一轮/去专项训练"。
- **验收**：≥3 轮后可结束并生成；刷新不丢；断网可生成；报告能跳到对应模块。

### 2.2 划词即查（P0，1 人日）

- **重构**：把 `linkWords` / `bindWordLinks`（`chat.js:67-93`）抽到 `core/` 公共层，阅读正文（`reading.js:215` 段落渲染处）、听力原文、写作批注三处接入。
- **查询**：先精确匹配 `LD_LEX`，再词干/变位还原，未命中走 LLM（异步，带"AI 释义"标记）。
- **写入**：`Store.addWord({de, zh, ctx, scene})`，来源句截断 120 字，与对话收藏同构（`store.js:17`、`:301`）。
- **验收**：阅读页点词出卡片；离线命中词库可用；生词本来源显示模块名；不破坏现有对话点词。

### 2.3 留德时间轴（P0，1 天）

- **数据**：静态数组 `[{stage:"APS", desc, modules:["interview"], months:"0-3"}, ...]`，不新增内容。
- **交互**：首页/计划页横向时间轴；已完成阶段按诊断结果与模考记录点亮；点击跳到模块。
- **验收**：新用户 10 秒内知道下一步；不引入新的数据依赖；移动端可横向滚动。

### 2.4 CEFR 路径壳（P1，3–5 天）

- **数据**：把现有词库分级、纠错句库、阅读包、听力包映射为 9 个单元（A1×3、A2×3、B1×3），每单元 3–5 个任务 + 1 个检查点。
- **解锁**：单元内知识点 BKT 掌握概率 ≥0.6 解锁下一单元（`engine.js:376-400`）。
- **边界**：只做导航壳，不宣称 CEFR 认证；内容仍来自现有池，避免"为了路径而造低质内容"。
- **验收**：路径页 9 单元可见；完成单元后解锁；不影响自由练习入口。

### 2.5 段落解析 + 配音（P1/P2，3 天）

- **段落解析**：每段一个"解析"按钮 → 长难句拆分、成分标注、中文翻译、语法点；结果按段落哈希缓存，避免重复计费；离线降级为"分句 + 词库释义 + 规则提示"。
- **配音**：MediaRecorder 录音 → `scoreSpeech` 评分 → 与原声对比音素差异；音频存 IndexedDB，只存元数据进 localStorage（配额约束）。
- **验收**：解析可缓存、可关闭；配音三步（听→录→对比）闭环，低分给最小对立对建议。

## 3. 反向问题：他们要抄我们，要付多少成本

答辩时比"我们有什么"更有力的是"**这个位置抄起来不划算**"。

| 我们的能力 | 竞品复刻需要 | 估算 |
|---|---|---|
| APS 题库 + 追问链 + 四维报告 | 中文市场内容 + 评分 rubric + 德语教研 | 1–2 个月，且非其主市场 |
| 按考试日期倒排（`engine.js:425`） | 技术上几天；产品上要放弃"日活最大化"的调度目标 | 组织决策，不是技术 |
| 离线单文件 / 可自托管 | SaaS 架构回不去；要重做交付形态 | 结构性成本 |
| 音素级"哪个音发错"（`phonetics.js:132`） | G2P + 对齐 + 最小对立对库 | 2–4 周 |
| 可改参数的算法沙盘（`engine.js:497`） | 确定性模拟器 + 愿意公开算法 | 黑盒产品不会做 |
| 三层降级（后端→直连→本地，`llm.js:100-152`） | 每层都要维护一套等价能力 | 长期维护成本 |

## 4. 明确不抄的清单

| 不抄 | 原因 |
|---|---|
| 视频通话 / 3D 虚拟人 | 实时链路与美术成本高，答辩演示增益低于"报告 + 沙盘" |
| 25 万词词典 | 授权费用与维护，工具属性可被免费替代 |
| 内容库规模竞赛 | 版权与录制成本；开放语料管线已够支撑演示 |
| 证书 / 学分 | 需要机构资质，短期不可能 |
| 社交联赛 / 好友榜 | 冷启动，赛期内无用户密度 |
| 复制真题/教材音频 | 版权红线；只仿题型，不抄题 |

## 5. 30 天落地顺序

| 周 | 任务 | 验收 |
|---|---|---|
| 第 1 周 | 课后报告 + 划词；修正 `competitive.js:10-24` 三处过时标注（Duolingo Max 口语、每日德语听力跟读/AI 解析、德语助手 AI 批改）；统计卡"17 功能模块"改为实时计数（实际 20 个） | 报告可生成、可回看；阅读可点词；矩阵与 2026-10 公开资料一致 |
| 第 2 周 | 留德时间轴 + 段落解析 | 首页 10 秒看懂路径；解析有缓存与离线降级 |
| 第 3 周 | CEFR 路径壳 + 配音页；题库扩容（每级 15 题起） | 9 单元可解锁；配音三步闭环；模考题目量够一轮 |
| 第 4 周 | 答辩资产：沙盘对照实验协议、价格对照页、复现成本不对称一页图 | 现场可改参数重跑；数字由页面实时生成 |

## 6. 合规与表述

- 只学机制，不抄界面、文案、题库、音频、词库；
- 不反编译、不抓私有接口、不绕过会员限制；
- 竞品功能标注日期与来源，未实测的不写"实测"；
- "复现"注明依据（论文 / 官方帮助中心 / 公开演示），推断性内容写"推测"；
- 开源叙事强调"方法与数据可审计"，不贬低竞品。
