# LinguaDE 3.15.0 长期使用报告：改对了三件事，也新引入三类问题

**一句话结论**：3.15.0 把「答辩作品」往「能用的产品」推了一大步——首页终于在对学习者说话、音标不再自相矛盾、单文件版不再是最穷的版本。但这一轮**治理工具自己制造了新的错误知识**（词形误标、等级错判），**内容厚度仍是天花板**（人工词条只占 29%、例句缺 18%–62%、粗口会进队列），而且**首屏出现了 6 个指向同一页的按钮**。综合 **7.0 / 10**：只用一个月 8.5 分，撑到三个月 6.5 分。

**我是谁**：备考 TestDaF 的中国学生，B1 起步，目标 4×4；Windows 笔记本 + Android 手机；先用单文件版，后用部署版（<演示服务器IP>）；按 90 天节奏真实走了一遍，日均 30–50 分钟。以下每条都带实测数字。

---

## 一、时间线

### 第 1 天｜首页终于在对学习者说话

双击 `dist/index.html`，**153 ms** 出诊断页，10 题走完到报告页 **2.1 秒**。大标题是「今天学什么」，副标题是「根据到期队列、错题和近期练习，今天最值得先做的是下面三件事」。赛事全名、模块数、词库规模被收进页面最底部的「关于」。**这是这一版最正确的改动。**

但首屏立刻暴露一个新毛病：折叠状态下我的 900px 首屏里有 **6 个区块**（hero、到期提醒、内容包横幅、今日三件事、考试倒计时、更多数据），其中**指向「单词练习」的入口有 6 个**——hero 两个按钮、到期横幅一个、考试卡两个、推荐卡一个。我理解每个都有理由，但视觉上就是同一句话喊了六遍。

另外内容包横幅只有「一键导入」，没有「以后再说」。它按「未导入」判定显示，意味着**只要我不点，它永远占着首屏第二屏的位置**。

### 第 1 周｜音标终于不打架了，但元音长度还是错的

词卡音标改成了和发音专项同一套 G2P。上一份报告点名的三个错全部核对：

| 词 | 上一版 | 这一版 | 词典实际 |
|---|---|---|---|
| Buch | `/buç/` ❌ | `/bʊx/` | `[buːx]` — 辅音对了，**元音长度还错** |
| Fenster | `/fɛnʃtɐ/` ❌ | `/fɛnstɐ/` ✅ | `[ˈfɛnstɐ]` |
| sechs | `/zɛçs/` ❌ | `/zɛks/` ✅ | `[zɛks]` |

我拿 2000 个词全量跑了一遍规则化体检，**可疑输出 22 条（1.1%）**，主要是 `-ie/-ie` 结尾吞掉词尾弱化（`Familie → famɪliː`，实际 `[faˈmiːliə]`）。人工抽查常用词，发现三类系统性问题：

- **元音长度一概不标**：`Tag → tak`（`[taːk]`）、`gut → ɡʊt`（`[ɡuːt]`）、`Hof → hɔf`（`[hoːf]`）。对初学者，长短元音是能被听出来的错误。
- **外来词首音一律德化**：`Vase → fazə`（`[ˈvaːzə]`）、`Video → fɪdɛɔ`、`Check → çɛk`（`[tʃɛk]`）。
- **带音标的词直接坏掉**：`Café → kaf`（é 不在允许字符集里，被吃掉，词尾整个丢了）。

卡片上「规则推导音标 · 非词典标音」这个标注是诚实的，我认可；但既然标注了「规则推导」，`Café → kaf` 这种**输出残缺**不该出现。

### 第 2 周｜治理工具开始「自信地报错」

`Falle` 的例句修好了，`leise` 也换成了 `Bitte sprich leiser…`。但词形归一这一项，我越用越不对劲：

```
Träume   → 标签「Traum 的复数 · 原形暂未单独收录」
leer     → 标签「leeren 的过去分词」        ← leer 是「空的」
Bombe    → 标签「bomben 的过去分词」        ← Bombe 是「炸弹」
Bär      → 标签「Bärin 的复数」，等级 C2    ← 熊被标成 C2
nah      → 标签「nahen 的过去分词」，等级 C1 ← 近的，被降到 C1
offenbar → 标签「offenbaren 的过去分词」     ← 「显然」
```

我查了全部 128 条词形标注：

- **7 条复数变体，原形 100% 不在词库里**（`Traum / Recht / Arme / Süße / Bärin / Deutsche / Vertraute` 全都没有）。也就是说：词库把名额给了复数，我却**永远学不到单数**。这正是上一份报告批评的原问题，我只是被贴了个标签。
- **121 条分词里 83 条的原形动词不在词库**。分词标签本身没错，错在**判定条件太松**：只要 kaikki 的某个动词词条的 forms 里出现这个词形就算，于是形容词 `leer`（空的）命中了动词 `leeren`（清空），名词 `Bombe` 命中了动词 `bomben`。

这一类比「没有标签」更伤信任：**产品用很确定的语气，教了我一个错的词性关系。**

### 第 3 周｜队列里出现了 Wichser

我用 30 天数据模拟「接下来 219 个新词」，抓到的真实队列里包含：

```
Karre   [C1]  释义「手推车」   ← 口语义是「汽车/破车」，释义本身也偏了
Wichser [B1]  释义「混蛋」
```

全库扫下来这类词有 4 条：`Wichser`(B1)、`ficken`(B1)、`Hurensohn`(B2)、`Kacke`(B2)。**B1/B2 意味着它们会正常排进新词队列**，卡片正面就是这个词。对一个准备进 TestDaF 考场的人，这是事故级内容问题。

同一批里还有 `piepen`(B2 吱吱叫)、`verknallt`(C2 迷恋的)、`Quatsch`(A2 胡说)——**词库没有任何语域标注**（口语/俚语/粗俗/书面），学习者无法判断「这个词能不能写进作文」。上一份报告说「词库是爬虫水平」，这一版把等级和例句洗干净了，但**语域这一层根本没建模**。

### 第 4 周｜好数据只够撑两个月

词库 2000 条里，**人工校订 572 条、机器对齐 1428 条**。新词队列我加了权重（人工 ×1、机器 ×0.4），所以前期体验很好——但按每天 10 个新词算，**57 天之后人工词池见底**，队列重新由机器词主导。实测第 30 天的队列：机器词 120 / 人工词 99（55%）。

例句覆盖按等级递减，这是硬数据：

| 等级 | 有例句 / 机器词条 | 覆盖率 |
|---|---|---|
| A2 | 109 / 169 | 64% |
| B1 | 378 / 655 | 58% |
| B2 | 155 / 407 | 38% |
| C1 | 13 / 41 | 32% |
| C2 | 29 / 155 | 19% |

A1/A2 里还有 **60 条常用词没例句**：`Ring`、`Insel`、`Drink`、`ehren`、`schreien`、`Angriff`、`Beförderung`、`Wirklichkeit`、`Jacke`、`Allianz`。上一版「宁可不显示也不给错例句」是对的，但**「不错」不等于「够用」**——一半以上的卡片背面是空的。

### 第 2 个月｜内容包进来了，但还是不可学

单文件版一键导入实测：阅读 **85 篇**、跟读 **300 句**、德中句对 **824 条**，导入后 localStorage 约 **634 KB**，零外部请求、零控制台错误。**这一项我给了很高分**——上一版「推荐的单文件版是内容最少的版本」的荒谬感消除了。

但打开阅读：

- 85 篇平均 **3497 字符**（约 600–700 词），6 段，全是维基式说明文；
- **中文对照 0 篇**（`paras[].zh` 全为空）；
- 每篇只有 3 道判断 + 3 道选择；
- 离线点「解析」，产品老老实实写「离线模式未提供整段翻译；配置大模型后可生成」。

结果就是：我一个 B1，在飞机上，面对一篇 700 词、零中文辅助、讲手球规则的历史章节的维基文，做完 6 道选择题。**内容有了，学习没有。**

听力更具体：跟读包 300 句里**只有 2 条真人录音，而且那 2 条是 Tatoeba 外链**。在 `file://` 下我点播放，程序正确地不发外部请求、回落浏览器 TTS——**也就是说单文件版永远听不到那 2 条真人录音**。离线优先做对了，代价是「唯一真人的声音」离线不可达。

写作 `LD_WRITING_BANK` **6 题**、对话 `LD_SCENES` **7 个场景**、面试 `LD_INTERVIEW_BANK` **12 题**、内置阅读 **5 篇**、内置听力句 **10 句 + 4 段双人对话**。这些数字这一版一个都没动。

### 第 3 个月｜冲刺期：重练有了，组卷没有

错题本确实有「开始错题重练」，卡片式翻面核对，这块比上一份报告的抱怨要好。但我要的是**「按错题类型重组的专项练习」**——现在重练是全量队列，不能按「冠词错了 12 个」「从句语序错了 8 个」组卷。

学习路径这一版补了「学完能做到 + 3 条语法讲解 + 10 个本单元词表」，我实测 A1 单元：

```
学完能做到：能用 3 句话完成姓名、来自哪里、住在哪里的自我介绍。
· 德语名词首字母大写；der / die / das 是名词的语法性别…
· ch 有两种读音：i / e 后读 [ç]（ich），a / o / u 后读 [x]（Buch）。
词表：kommen 来 · wohnen 居住 · das Land 国家 · die Sprache 语言 · der Tag 天 …
```

**这是「导航壳」变「课」的第一步，我认可。** 但检查点仍然是纯判分：我故意全答错，交卷只给「30 分 · 未达到 70 分；建议先完成本单元任务，再重测」——**不告诉我哪 7 个词错了、错在哪**。讲解有了，验收没有闭环。

### 期间｜数据与同步：这次真的会拦我了

- 导出 JSON 带 `fnv1a` 校验和。我手改文件里一个字段再导入，被明确拒绝：「校验和不匹配：导出文件可能被修改或截断，已拒绝导入」。✅
- 云端冲突：接上真实后端，我在另一台设备推了一份更新的快照（500 条记录），本机点「同步到学习云」，弹出：

  ```
  云端快照比本机新：
  云端 2026/11/1 21:02:55 · 记录 500 条
  本机 2026/11/1 20:02:54 · 记录 5 条
  继续同步会用本机数据覆盖云端。建议先取消…仍要覆盖云端？
  ```

  ✅ 上一版「我在手机上背了 20 个词，晚上电脑一同步就没了」的**静默**问题解决了。但**合并仍然没有**——它只是把事故变成了需要我自己判断的事故。

### 期间｜一个自相矛盾的状态（可复现）

我造了 40 个「到期词」，但这些词不在当前词库（换设备恢复旧快照、词库改版后删词、手动改 localStorage 都会造成这种状态——上一份报告里就有用户手动改 localStorage）。结果：

- 首页横幅：**「你已隔日未复习 —— 40 个词条正在滑向遗忘」**
- 点进单词练习：**「今日没有到期词条 —— 词库共 2000 词已进入复习周期」**

`dueCount() = 40`，`buildQueue() = 0`。**同一屏上产品先说你有 40 个词要忘，再告诉你今天没词可学。** 孤儿卡片被静默丢弃，没有任何解释或清理入口。

### 期间｜性能长尾

单文件从 929 KB 涨到 **1,673,125 B**（gzip 后 **597,574 B**）。本地 `file://` 打开：DOMContentLoaded **60 ms**，无感。线上同一台 4 Mbps 按流量 ECS，我连测 6 次：

```
0.16s / 0.23s / 0.41s / 0.87s / 14.72s / 18.79s
```

未压缩版另测两次：**40.4s 和 2.1s**。也就是说**约 1/3 的访问会卡在十几秒**。上一版 gzip 后约 220 KB，这一版 598 KB，长尾被拉长了近 3 倍。而 nginx 的 `gzip_comp_level` 没设（默认 1）：本地实测 level 1 → 707 KB、level 6 → 507 KB、level 9 → 494 KB，**一行配置能再省 15%**。

## 三、这一版**新引入**的问题（按严重度）

1. **词形标签的「自信错误」**：`leer→leeren`、`Bombe→bomben`、`Bär→Bärin(复数)`、`nah→nahen`、`offenbar→offenbaren`。判定条件太松（词形字符串命中即算），且**等级跟着 base 走**，于是 Bär 从原来的等级掉到 C2。
2. **复数变体占位但原形缺失**：7 条全部如此。学习者学到 `Träume` 却学不到 `Traum`。
3. **10.5px 小字**：`.phon-note`（音标说明）、`.module-tab small`（页签注释）、`.path-word small`（词表中文）——直接违反这一版自己刚定的「提示文字统一到 12.5–13px」。
4. **首屏 6 个入口指向同一页 + 3 个横幅堆叠**：折叠做对了，去重没做。
5. **首屏体积长尾**：598 KB gzip，实测 1/3 请求 15–19s；`gzip_comp_level` 未设。
6. **到期孤儿词静默丢弃** → 「40 个词要忘」与「今天没词」同屏矛盾。
7. **游戏化开关分组错位**：在「数据管理」而不是「学习设置」。
8. **内容包横幅没有「以后再说」**，未导入就永久占位。
9. **mock 后端与真实契约脱节**：`MOCK_SNAPSHOT` 没有 `_snapAt`，`updated_at` 是固定过去时间；前端 `+isoString` 得到 `NaN`。结果：**冲突提示这条新逻辑，119 项测试里 0 覆盖**——它现在能工作只是因为真实后端恰好存了 `_snapAt`。

## 四、升级建议

### P0：下一轮就做（每项 ≤1 天）

1. **给词形标签加闸门**：只有「base 在词库内 + 词性一致 + kaikki 明确标了 participle/plural」三条同时成立才写 `formOf`；否则退回普通词条。**宁可不标，不要标错。** 顺手把 `Bär` 的等级改回 A2。
2. **内容红线三件套**：`register` 字段（书面/口语/俚语/粗俗）+ 粗口词从学习池剔除（保留查词）+ 释义抽查修复（`Karre`）。词库治理工具加一条红线校验，`test_content.py` 把它并入质量门。
3. **复数变体二选一**：要么把 `Träume` 改写成 `Traum`（复数写进新字段），要么把这 7 条让位给真正缺的基础词（`Traum`、`Recht`、`Bär` 等）。当前状态最差。
4. **首屏去重**：hero 只留「开始今日队列」+「更多数据」；到期横幅与考试卡各留一个动作；横幅加「今天不再提示」（写进 `contentPacksImported` 同级的 dismissed 记录）。
5. **小字回 12px、gzip_comp_level 6、内联内容包分级**：默认只内联阅读 + 跟读（约 472 KB），双语句对留给部署版/手动导入；或把内联数据 gzip + base64，首次运行时 `DecompressionStream` 解压进 IndexedDB，让首屏回到 ~1 MB / gzip ~300 KB。
6. **孤儿到期词可见化**：`buildQueue` 统计「到期但不在词库」的数量，空态文案改成「X 个到期词不在当前词库（可能来自旧版本或已删除）」+ 一键清理记录。

### P1：决定 3 个月后的留存

7. **例句扩容**：Tatoeba 增量抓到 5000 句对（现在 824），目标 A1/A2 无例句清零、B1 覆盖 ≥80%。
8. **人工词条从 572 → ≥1200**：按新分级抽机器词条做人工复核，每批 100 条，把「好数据」占比推过 50%。这是词库体验的根，不是补丁能解决的。
9. **错题本按类型/等级组卷**（冲刺期真实需求）；检查点加逐题回顾 + 错因，而不只是分数。
10. **阅读内容考试化**：维基长文 → 300–450 词 + 每篇 1 段中文导语 + 小标题匹配题。或者干脆承认它是「泛读素材」，别放在「阅读理解（TestDaF 题型）」名下。
11. **把真人音频打进 dist/audio/**：至少那 2 条 CC 授权的，让单文件版第一次能听到真人的德语。
12. **字段级合并**：`cards`/`hlr` 按 `last` 时间戳取较新者，冲突时只做提示的场景收敛到 profile/ability。

### P2：打磨

13. 词卡补复数/变位/搭配（kaikki `forms` 里已有，取 1–2 个字段就够）。
14. G2P 补元音长度与外来词例外表（或对外来词干脆不显示音标，只显示发音按钮）。
15. e2e 补两条：同步冲突提示、单文件内容包离线导入；mock 后端补 `_snapAt` 与真实时间戳。

## 五、如果只改三件事

1. **停止「自信的错误」**：词形标签加闸门 + 粗口/语域红线。这一版最伤信任的不是没修好，而是修出了新的错。
2. **把内容厚度做上去**：例句覆盖 + 人工词条占比 + 阅读考试化。调度和算法已经是这个产品最好的部分，内容配不上它。
3. **首屏去重 + 体积长尾**：6 个 CTA 收成 2 个，gzip 与内联策略调好。

## 六、给不同的人

- **B1/B2 冲刺者**：单词 + 错题本 + 模考依然是最值三件套；**但别把机器词表的词直接写进作文**（`Karre`、`Wichser`、`piepen` 都在里面），口语/写作用词先过一遍发音专项或问老师。
- **A1/A2 初学者**：比上一版友好很多（A2 词从 59 → 228），可以先当主复习工具；但主教材仍要另配，因为一半卡片没例句。
- **老师/机构**：调度闭环和诚实标注适合做辅助工具；多设备合并、班级、内容审核依旧没有，别直接发给学生。
- **答辩演示**：`file://` 双击 → 先点「一键导入」→ 演示「今天学什么」→ 打开「今天为什么练这 20 个词」→ 在词卡上点一次「报错」→ 设置里关掉游戏化。**这条 3 分钟的动线，比念「19 个模块」有说服力得多。**
