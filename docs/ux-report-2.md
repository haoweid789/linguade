# LinguaDE 使用体验报告 · 第二号（学习者视角）

> 来源：以「新用户真实走查」为方法的第二份使用体验报告（备考 TestDaF 的学习者视角）。
> 走查口径：当前构建（3.5.0-c）从新用户完整路径重新走一遍 —— 诊断 → 核心循环 → 全真模考 → 导入内容包 → 逐个点开全部 20 个模块。
> 结论：报告 #1 的必走问题全部核销；下一轮唯一重要的事是**内容纵深**（候选词富化入库 + 分级阅读）。

**报告人**：还是那个备考 TestDaF 的学生。距离我写第一份报告（当时词库 309 词、配了云端等于没配、手机上没有导航）过去了一个迭代周期，我用**当前构建**重新从新用户走了一遍完整路径：诊断 → 核心循环 → 全真模考 → 导入内容包 → 逐个点开全部 20 个模块。以下所有数字来自今天 23 点前的实测，不是宣传口径。

## 二、这一轮的新体验亮点

导入 `content-pack-speech.json` 的瞬间最能体现这个产品的变化：口语测评句单从"10 句背到吐"变成 **775 句**，其中标着"Tatoeba·实人录音"的条目可以对照真人发音——这是第一份报告里"跟读池 1–2 天见底"那个最紧迫问题的正面回答。全真模考走完四节拿到 TDN 报告后，我发现它诚实地写着"启发式换算，非官方"——这种不吹牛的标注让我更愿意信它的其他分数。

## 三、仍然缺失的功能（按学习者受伤程度排序）

**🔴 内容纵深仍未到"备考主力工具"水准**
- **词汇 476 vs 歌德 A1-B1 官方词表约 2400**：B2/C1 只有首批 167 词。管线已产出 4764 个候选高频词清单（`docs/content-pipeline-report.md`），但"无中文释义不进词库"的红线卡着——下一步必须做 LLM 批量富化+人工抽检（3.5.0-d）。这是当前最大的单一缺口。
- **阅读池还是 5 篇**（约一周耗尽）：内容管线这轮只喂了跟读池，阅读池的 Simple German Corpus 精选（50–100 篇分级短文）还没做。
- 写作 6 题、面试 12 道：模考会复用它们，重复率升高得比想象快。

**🟡 真实听感仍是短板**
- 全部听力依赖 TTS，双人对话虽有两个音色，但离考试的对话语速/口音多样性还远；内容包 300 句里**授权干净（非 NC）的实人录音只有 2 条**——Tatoeba 随机采样里 NC 授权占了大多数。全量导出（--bulk）能提高命中，但 219MB 在弱网下没跑完。
- 口语评分是"文本比对"级：能告诉我流利度和准确度，但**说不出我具体哪个音发错**（ü/u、ch 这类最小对立对已在发音专项里，但测评报告不做音素定位）。

**🟡 内容包的"发现性"问题**
- 我知道要导入 `content-pack-speech.json` 是因为我读了工程文档。一个部署版用户打开网站，**没有任何提示告诉他存在 300 句内容包**。建议：部署形态下首页/设置检测同源 pack 文件并给一键导入按钮。

**🟢 次级诉求**
- **语法没有"课程树"**：语法点散在纠错/专项/弱点三个模块里，对 A1-A2 零基础者缺一条"从零到 B2 按语法点顺序学"的路径；
- **多设备并发**是整快照覆盖（后写赢），同时用手机+电脑会丢一边的数据；
- **学习周报/分享图**：学情分析有趋势但缺"本周小结"这种可分享的成就感载体；
- 「竞品对比」页仍混在学习导航里（是答辩材料不是学习功能，第一份报告提过，这轮因测试链改动成本没动）。

## 四、一句话结论

**第一份报告里"配了云端等于没配、换设备白学、手机残废"这三个让我必走的问题已经全部解决，现在的 LinguaDE 是一个我能连续用一个月不出戏的工具；但要从"能用的备考陪伴"变成"备考主力"，还差内容纵深这最后一座山——4764 个候选词的富化入库和 100 篇分级阅读，是下一轮唯一重要的事。**
