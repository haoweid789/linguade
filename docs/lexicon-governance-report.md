## 做了什么

1. **分级**：1428 条机器词条原本 995 条标 B2。改为按字幕词频估计（非官方 CEFR 认定），并用人工覆盖表校正高频基础词（Dorf / halb / schwierig / leise 等）。
2. **例句**：三层选句 —— ① 原句带中文且通过词形校验就保留；② 从德中句对池（Tatoeba，含考试库 sentences 表）取该词最干净的一句；③ 池里配不到句的走人工覆盖表 `tools/data/lexicon9_example_overrides.json`。可分动词要求前缀落在句末（er stellt ein），句中首字母大写的同形名词不算动词命中。本轮机器词条例句覆盖 1428/1428，例句缺中文 0。
3. **简繁**：全部词条释义与例句中文经 OpenCC `t2s` 统一为简体。
4. **词形**：复数名词（如 Träume → Traum）与过去分词（如 genannt → nennen）写入 `formOf` / `formKind`；复数变体不再进入新词队列，分词在卡片上标注来源。
