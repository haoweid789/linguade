# LinguaDE · AI 多模态双语留学自适应学习陪伴系统

> 第十一届华为 ICT 大赛创新赛 · 赛题一 ｜ 开源 ｜ 离线优先 ｜ **零运行时依赖**

面向留德备考群体（TestDaF / DSH / Telc / 歌德）的自适应学习陪伴系统：从入学能力诊断出发，覆盖听说读写与专项语法，用自研调度算法安排每一次复习，错题与生词自动沉淀并反向驱动学习计划。

## 一、快速开始

| 方式 | 操作 | 适用场景 |
|---|---|---|
| **单文件版（推荐）** | 直接用浏览器打开 `dist/index.html` | 无需任何环境，双击即用，可离线、可拷走分发 |
| 源码版 | 工程根目录 `python -m http.server 8899` 后访问 `http://127.0.0.1:8899/index.html` | 开发调试（可加载 `src/**` 并接后端） |
| 完整版（含后端） | `cd backend && pip install -r requirements.txt && uvicorn app.main:app`，前端设置里填写后端地址 | 云端大模型 / 语音转写 / 拍照批改 / 多端同步（后端可选，不配前端仍完整可用） |

> 首次进入会先做 10 题入学诊断，之后自动落到首页。学习档案默认保存在浏览器本地（localStorage + IndexedDB 镜像/快照），不上传、无追踪；若清理浏览器站点数据，本地快照也可能一并被清除，建议定期导出 JSON，或主动配置后端同步。

### 质量门（一键）

```bash
python tools/build.py        # 同步模块脚本段 + 打包单文件 dist/index.html
python tools/check.py        # 一致性校验：模块注册 / 元数据 / index 脚本 / 外链 / 闭合
node tools/smoke.mjs         # 装配冒烟：在 Node 里按序执行全部内联脚本
python -m pytest tests -q    # 全量回归（344 项：251 e2e + 93 API/单元；需先装 tests/requirements-dev.txt）
python tools/test_content.py             # 内容产物校验：内容包 schema / 授权红线 / 词库中文释义
python tools/content_pipeline.py --all   # 外部语料管线：Tatoeba → 跟读内容包（幂等可重跑）
python tools/fetch_audio.py --write --fetch  # 真人录音进包：Tatoeba 音频 → dist/audio + 单文件内联
python tools/review_worklist.py --write  # 人工复核清单：例句缺口 / 词形缺原形 / 抽检 / 阅读考试化
python tools/review_batch.py --write      # 3.20 内容复核批次：A1–A2 词条结构校验 → AI 辅助自动复核集合
python tools/import_german_exam_db.py    # 考试库 ETL：german_exam.db → lexicon-10 / 语法速查 / 考试结构
python tools/reading_pipeline.py --all   # 阅读池管线：维基百科 → 分级短文内容包（幂等可重跑）
python tools/ocr_eval.py --selftest   # OCR 评测自检（真实基线：--channel backend / api）
# 或一条命令：powershell -File tools/test.ps1   （任何一步失败都会终止并报退出码）
```

e2e 需要开发依赖：`pip install -r tests/requirements-dev.txt && python -m playwright install chromium`（**仅测试用，不进入运行时产物**）。

## 三、模块化内核

```js
// src/modules/ocrgrade.js —— 一个模块 = 一个文件（含元数据）
LD.define("ocrgrade", Object.assign({
  title: "拍照批改",
  render(host, ctx) { /* ctx = { go, payload } */ }
}, { label: "拍照批改", icon: "▨", group: "沉淀与复盘", priority: "P0", order: 98, ds: "拍照/上传手写德语 → 识别转录 → 批改" }));
```

- **新增模块**：只写 `src/modules/x.js`，再跑 `python tools/build.py` —— 脚本引用、导航、首页与排序**全自动**（3.1.0 的「发音专项」与 3.3.0 的「拍照批改」都是这样加的）；
- **导航与首页**由 `LD.modulesByGroup()` 统一生成，不存在「两处维护」；
- **一致性**由 `tools/check.py` 强制保障（模块文件 / `LD.define` / index 脚本 / 顺序 / 外链 / 闭合）。

## 五、核心算法体系（全部自研、公开可审计）

| 算法 | 模型 | 用途 |
|---|---|---|
| **HLR 半衰期记忆模型** | 复现 Duolingo 论文（Settles & Meeder, ACL 2016）：`p = 2^(-Δ/h)`，答对半衰期增长（边际递减）、答错减半（下限 0.5 天） | 按遗忘概率调度复习，濒危词优先 |
| **BKT 贝叶斯知识追踪** | 四参数模型，输出知识点掌握概率与预测正确率 | 弱点识别、组卷依据 |
| **SM-2 间隔重复** | 简化变体（EF∈[1.3,2.5]），沙盘中复现标准规则作对照 | 单词卡基础调度 |
| **fitToExam 考试倒排** | 以考试日为锚压缩复习间隔 | 冲刺期调度 |
| **算法沙盘模拟器** | 确定性虚拟学生（seeded PRNG）同场驱动 **HLR / SM-2 / Leitner / FSRS** 四套调度器 | 算法优势的可验证证据 |
| **内容分 / 发音分分离** | 内容分 = WER（Levenshtein）+ 语速流利度；发音分 = 转写文本 → 规则音素序列对比（PER 近似）；手动输入不评发音，报告带置信度 | 跟读与复述评分，避免把「识别对了」当成「发音准了」 |
| **音素级发音定位** | 规则式 G2P（德语特例：ch 双音位 [ç]/[x]、词尾弱化、词首浊化）+ 音素序列 Levenshtein 对齐 + 最小对立对库（GOP 思路：Witt et al. 2000 / Hu et al. 2015） | 指出「**哪个音发错**」（如 ü→u） |
| **FSRS 目标保持率调度** | `interval = S / FACTOR × (R^(1/DECAY) − 1)`（Anki / FSRS-rs 同式；`DECAY = −0.5`），R 可在 70–97% 调节 | 保持率 ↔ 复习量的用户可控权衡 |
| **指数平滑能力值** | 对/错 ±1.2/1.6 在线更新六维能力 | 难度自适应 |

## 六、AI 三层降级

```
① 后端 FastAPI（华为云 MaaS 视觉/文本大模型 · 昇腾 Whisper 语音）
        ↓ 不可用
② 浏览器直连大模型（OpenAI 兼容，支持 vision 传图）
        ↓ 不可用
③ 本地规则引擎（纠错/评分可用；手写图像识别明确提示需 AI 通道）
```

覆盖四条链路：
- **文本**：纠错 `LD.LLM.correct`、对话 `LD.Backend.chatStream`（**SSE 流式**，失败回落 `LD.LLM.reply`）、中文→德语 `LD.LLM.translateZh`（对话室中文输入，后端 `/api/ai/translate` → 直连）、面试评估 `LD.LLM.evaluateInterview`；
- **对话室人设**：`chatPersona` 随对话上行（`persona` 字段），后端在场景提示词后叠加人设提示；离线时人设影响开场白、朗读语速与提示口径，不伪造回复。
- **连接诊断**：设置 → AI 配置组顶部的 **「检测连接」** 按钮真实调用一次模型（`/api/admin/llm-test`），直接显示接口类型、模型、耗时、回复或供应商原始错误；设置抽屉同时读取 `/api/health` 显示后端/大模型状态。对话主页面不显示连接状态条；后端 AI 失败时，对话点评会写明“本地规则 · 原因”，不再静默回落。
- **三种接口适配**：`llm_api_style` 可选 `openai`（Bearer，地址自动补 `/chat/completions`，也接受完整地址）/ `azure`（`api-key` + deployment + api-version）/ `custom`（完整地址原样请求，适配华为云 MaaS 部署地址或自建网关）；对话、流式、纠错、翻译、拍照批改共用同一套构造。
- **语音**：`LD.ASR` 华为云/后端 Whisper → 浏览器识别 → 本地录音回放 + 手动文本 → 手动输入；后端转写配置继续保留，`file://` 下使用本地可用的降级通道；
- **图像**：`LD.LLM.ocrGrade` 拍照/上传 → 后端视觉 LLM 一次性完成「转录 + 批改」（语法纠错 / 练习批改 / 写作批改）；
  独立入口为「拍照批改」模块，**句法纠错 / 写作批改**内也各嵌了「📷 从图片导入」（自动切 mode，复用 `LD.OCRUI`）；
- 设置抽屉显示 `/api/health` 的**后端 / 大模型 / 语音 / Redis** 状态徽标。
- **可选增强通道（3.7.0）**：音素评估（`rule` 默认 / `acoustic` 外部声学服务）与知识追踪（`bkt` 默认 / `dkt` 外部深度模型）均为**可插拔后端通道** —— 未配置即走零依赖本地实现（与前端同口径），`/api/health` 显示**实际生效**通道，外部服务故障自动回落；启用方法见 `docs/deploy-guide.md`。

## 八、数据导出 / 导入与开源边界

- 生词本 → **Anki 兼容 TSV**（`front / back / source`），亦可从 Anki TSV **导入**生词本
- **内容包（三种，同构「一键导入」契约）**：
  - 跟读 `dist/content-pack-speech.json`（Tatoeba 德语实句 300 条；实人录音仅保留授权明确且非 NC 的条目，其余 TTS 即读）— `python tools/content_pipeline.py --all`；
  - 阅读 `dist/content-pack-reading.json`（维基百科分级短文 **86 篇**，A2/B1/B2 同批相对分位，逐篇带 CC BY-SA 4.0 来源链接）— `python tools/reading_pipeline.py --all`；
  - 词库册 `dist/content-pack-lexicon.json`（LLM 富化词条，**无中文释义不入库**）— `python tools/lexicon_enrich.py --pack`；
  导入后对应池即时扩容（阅读池 = 内置 5 篇 + 内容包；词库册幂等并入内存词表，刷新不丢）
- 学习记录 → **CSV**（带 BOM，Excel 直接打开）
- 全量数据 → JSON（设置抽屉导出），亦可**导入恢复**（保留本机设置与设备标识）
- **云端快照**：配好后端后，同步自动上行全量学习快照（剔除 API Key 等凭据）；「从云端恢复」一键拉回——换设备/清缓存不再丢学习档案
- 默认数据全部留在浏览器本地；仅在主动配置后端后才同步，无任何第三方追踪
- 拍照批改的图片仅在用户主动提交时上传，服务端处理完即弃、不落盘
- **生词本四入口**：对话点词收藏、**对话室「保存当前句」整句收藏**、**手动添加 + 内置词典查询**（命中词库自动回填中文释义）、Anki TSV 导入
- **写作进步可见**：同题再次批改显示「↑/↓ N vs 上次 X 分」对比徽标；每次批改入档（上限 50），侧栏「历次成绩」列最近 6 次并按分数着色
